# 🛒 MERN Cart Functionality App

This is a full-stack web application built using the **MERN stack (MongoDB, Express, React, Node.js)** that showcases the **cart functionality** in an e-commerce-like interface. Users can add items to the cart, and all data is persisted in **MongoDB**.

---

## 🚀 Features

- ✅ Add items to the cart
- 🧠 State management using **Zustand**
- 🌐 Backend built with **Express.js** and **MongoDB**
- 🎨 Frontend built using **React** and **Tailwind CSS**
- 🔄 Persistent cart data stored and retrieved from the database
- 🧩 RESTful API integration between frontend and backend

---

## 🛠️ Tech Stack

### Frontend
- **React 19**
- **React Router DOM 7**
- **Zustand**
- **Tailwind CSS**
- **Lucide-react**
- **Vite**

### Backend
- **Node.js**
- **Express.js 5**
- **MongoDB** with **Mongoose**
- **CORS**
- **Body-Parser**
